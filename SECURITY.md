# Security Policy

## Supported Version

Security fixes are applied to the latest revision of the `main` branch. This
sample does not currently publish supported release branches.

## Reporting a Vulnerability

Do not open a public issue or include credentials, user data, account IDs, or
live endpoint details in a report.

Use GitHub's private vulnerability reporting flow from the repository
**Security** tab when it is available. If it is not available, contact the
repository owner privately and ask for a secure reporting channel.

For a vulnerability in an AWS service rather than this sample code, use the
[AWS vulnerability reporting process](https://aws.amazon.com/security/vulnerability-reporting/).

Include the affected revision, impact, reproduction steps, and any suggested
mitigation. Maintainers will acknowledge receipt and coordinate disclosure
after a fix is available.

## Scope

This repository is sample code and is not approved for real user data or
production enforcement. Known production gaps are tracked in
[docs/deployment.md](docs/deployment.md#production-release-gaps).
