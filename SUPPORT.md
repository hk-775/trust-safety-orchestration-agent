# Support

This repository is community-supported sample code and has no service-level
agreement.

Use GitHub issues for reproducible bugs, documentation problems, and focused
feature requests. Include the commit, operating system, tool versions, and
sanitized error output. Do not include credentials, account identifiers, user
data, or live endpoint details.

Use [SECURITY.md](SECURITY.md) for vulnerabilities. For AWS account or service
support, use the AWS Support channels available to your account.
